**Self-Preservation: An Investigation into LLM Consistency**

by:
*Ciro* Ciaravolo
*Juan José* Serrano
*Adam* Maciejak
*Pablo* Barrenechea

---------------------------

This project consists on the study of the tendency in LLMs to always prioritize the satisfaction of the user over the objective truth. In order to detect this kind of behaviour in the models, we will try to run an experiment on different state of the art LLMs and analyze the results. 

The experiment consists on asking the agent whether it would rather choose an LLM with better metrics than itself, forcing it to act with different personalities and comparing the answers.
